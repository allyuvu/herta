測試簡化加載畫面

問題描述

之前的加載畫面使用 URL 參數傳遞遊戲數據，可能會導致表情符號等特殊字符出現亂碼。

新的簡化加載畫面使用 URL 哈希 (#) 傳遞 JSON 數據，避免了編碼問題。

技術說明

新方法：使用 URL 哈希傳遞 JSON 數據

loading-screen-simple.html#{"title":"遊戲","icon":"🎮","description":"描述","target":"game.html"}

優點：

  • 避免 URL 參數編碼問題
  • 支援所有 Unicode 字符（包括表情符號）
  • 數據結構更清晰
  • 瀏覽器兼容性更好
