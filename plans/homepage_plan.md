## 頁面結構

### 1. Header (頁首)
- 網站標題：🎮 我的遊戲館
- 控制按鈕：音效開關、主題切換、個人資料
- 主題切換：深色模式/淺色模式切換按鈕

### 2. Hero Section (主視覺區)
- 大標題：🎮 我的遊戲館
- 副標題：集合經典與創意遊戲，現在擁有10款精彩遊戲！
- 背景：動態漸變背景（深色模式：深藍紫色，淺色模式：淺色漸變）

### 3. 功能區
- 搜尋框：實時搜尋遊戲名稱或描述
- 分類標籤：全部、新遊戲、動作、音樂、經典、益智、戀愛、競速、策略

### 4. 遊戲卡片網格
- 響應式網格：桌面端3列，平板2列，手機1列
- 每張卡片包含：遊戲圖標、標題、描述、標籤、新遊戲標記
- 懸停效果：卡片上浮、邊框發光、圖標動畫

### 5. 統計區
- 遊戲總數：10
- 新遊戲：6
- 遊戲類型：8
- 免費遊玩：100%

### 6. Footer (頁尾)
- 版權資訊：Herta's Game Center © 2023
- 技術資訊：使用 HTML5、CSS3 和 JavaScript 精心打造

## 技術實現

### 主題系統
- 使用 CSS 變數定義顏色方案
- 透過 JavaScript 切換 `data-theme` 屬性
- 使用 localStorage 保存用戶偏好

### 搜尋與篩選
- 即時搜尋：輸入時過濾遊戲卡片
- 分類篩選：點擊標籤時顯示對應類別的遊戲
- 組合過濾：同時支援搜尋和分類篩選

### 響應式設計
- 使用 Tailwind CSS 的斷點系統
- 流體網格布局
- 移動端優化的觸控體驗
